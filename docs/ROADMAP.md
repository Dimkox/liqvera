# Liqvera roadmap

## Implemented

Public capture, exact analysis, canonical report and evidence ZIP construction, offline verification, browser wallet/quote/delivery flow, PostgreSQL gateway, guarded Mezo payments, isolated Compose profiles exist in this repository. Historical paid testnet delivery is recorded in published releases.

## Current work

Standalone documentation, technical identifiers and the audited production rollout are complete. The public demo runs on Mezo Testnet with preserved historical payment state and the unchanged owner recipient/0.01 test-MUSD price. Mainnet configuration and its separate ledger remain available for a future switch. Public HTTPS, preview downloads and browser checks pass. Merchant checkout is enabled with per-purchase wallet authorization, fixed terms and durable nonce protection. Fresh quote/challenge checks pass; a new paid-delivery acceptance on the current Testnet deployment remains to be recorded.

## Release gates

Run the complete local suites, real disposable database integration and canonical installed-wheel verification. Verify fixture zero-egress behavior and browser recovery. Bind built images and acceptance results to the exact clean source. Preserve unresolved NOT_RUN cases and require explicit authorization for any new testnet settlement. Back up durable state and prove recovery before migration or rollout.

## Deferred

Remaining external acceptance cases require explicit execution and evidence. Additional instruments need economic identity mapping and source validation. Custody, private venue access, exchange order execution, withdrawals and personalized trading advice are outside the current product boundary.
