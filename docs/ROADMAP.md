# Liqvera roadmap

## Implemented

Public capture, exact analysis, canonical report and evidence ZIP construction, offline verification, browser wallet/quote/delivery flow, PostgreSQL gateway, guarded Mezo payments, isolated Compose profiles and Linux installer contracts exist in this repository. Historical paid testnet delivery is recorded in published releases.

## Current work

Standalone documentation, technical identifiers and the audited production rollout are complete. Mainnet configuration is deployed with separate ledger state and unchanged owner recipient/price. Public HTTPS, preview downloads and browser checks pass. Merchant checkout is enabled with per-purchase wallet authorization, fixed terms and durable nonce protection. Fresh quote/challenge checks pass; real Mainnet paid-delivery acceptance remains to be recorded.

## Release gates

Run the complete local suites, real disposable database integration and canonical installed-wheel verification. Verify fixture zero-egress behavior and browser recovery. Bind built images and acceptance results to the exact clean source. Preserve unresolved NOT_RUN cases and require explicit authorization for any new testnet settlement. Back up durable state and prove recovery before migration or rollout.

## Deferred

Installer update/rollback requires coherent backup and migration-ledger support. Remaining external acceptance cases require explicit execution and evidence. Additional instruments need economic identity mapping and source validation. Custody, private venue access, exchange order execution, withdrawals and personalized trading advice are outside the current product boundary.
