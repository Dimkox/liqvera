# Liqvera roadmap

## Implemented

Public capture, exact analysis, canonical report and evidence ZIP construction, offline verification, browser wallet/quote/delivery flow, PostgreSQL gateway, guarded testnet payments, isolated Compose profiles and Linux installer contracts exist in this repository. Historical paid testnet delivery is recorded in published releases.

## Current work

Finish the approved technical namespace migration on the complete application; remove obsolete development-process dependencies; remediate and rescan Python, npm and container dependencies; verify isolated service operation and preserve published artifact identity. Resolve the existing gateway startup failure through bounded diagnosis before any reviewed deployment.

## Release gates

Run the complete local suites, real disposable database integration and canonical installed-wheel verification. Verify fixture zero-egress behavior and browser recovery. Bind built images and acceptance results to the exact clean source. Preserve unresolved NOT_RUN cases and require explicit authorization for any new testnet settlement. Back up durable state and prove recovery before migration or rollout.

## Deferred

Installer update/rollback requires coherent backup and migration-ledger support. Remaining external acceptance cases require explicit execution and evidence. Additional instruments need economic identity mapping and source validation. Mainnet payments, custody, private venue access, exchange order execution, withdrawals and personalized trading advice are outside the current product boundary.
