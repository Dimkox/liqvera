# Liqvera competition description

Liqvera — Market reports you can verify — turns public Hyperliquid BTC perpetual snapshots into exact market reports and portable evidence bundles. Users can inspect snapshot depth, hypothetical BUY/SELL sweep calculations, quality checks and source limitations, then verify exported artifacts offline. Reports do not promise execution or profit.

The complete browser and gateway implement report requests and guarded 0.01 test-MUSD access payments on Mezo Testnet. Historical reviewed payments delivered immutable JSON and ZIP artifacts without charging again on retrieval. New payments require valid external authority, canonical finality and an explicit testnet execution decision. A wallet-free historical preview is separately labelled with its source timestamp.

The latest published source release is v0.0.5; the current standalone component migration is unpublished. Overall acceptance remains incomplete: 9 historical PASS and 21 NOT_RUN. Present current availability, security findings and validation evidence honestly; do not reuse a historical transaction as proof of a new run.
