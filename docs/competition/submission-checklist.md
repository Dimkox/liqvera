# Liqvera submission checklist

- Record the exact clean source commit and published release URL.
- Link the browser demo and state its observed availability and timestamp.
- Distinguish the wallet-free historical preview from a fresh report.
- Include report/ZIP digests and matching offline-verifier instructions.
- Cite historical testnet settlement evidence without implying a new payment.
- Include all acceptance omissions: the historical aggregate is 9 PASS and 21 NOT_RUN.
- Report current dependency findings and unresolved runtime failures.
- Verify public material contains no secrets, wallet signatures or bearer capabilities.

A fixture walkthrough, mock or partial result is not end-to-end paid acceptance.
