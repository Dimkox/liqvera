## Reproduce

Run `python3 /path/to/getzilla/scripts/getzilla_vulns.py --online --json` from the clean source checkout. Run `npm audit --json --prefix apps/mezo-gateway` and the corresponding web command. For each exact image ID, run `trivy image --scanners vuln --image-src docker --format json IMAGE_ID` after refreshing the vulnerability database. Do not replace live image tags while testing.
