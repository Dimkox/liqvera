# Accepted ADR — Liqvera report and payment boundary

The narrow F1 decision is accepted in
[ADR-0002](../../../docs/adr/0002-liqvera-report-payment-boundary.md).

It establishes runtime, immutable-artifact, ledger, and testnet-only authority.
F2 API payloads, database schemas, reason codes, and state graphs remain open.
Acceptance is neither payment readiness nor release authorization.
