# Data dictionary

| File | Contents |
|---|---|
| `apk-summary.json` | Binary identity and inventory totals. |
| `android-permissions.csv` | Declared permissions. |
| `android-components.csv` | Activities, services, receivers and providers. |
| `deep-links.csv` | Intent-filter schemes, hosts and paths. |
| `custom-android-classes.csv` | Package-local DEX classes. |
| `custom-android-members.csv` | Package-local fields/method signatures. |
| `capacitor-plugins.csv` | Capacitor package/class registrations. |
| `stores.csv` | Pinia store IDs and locations. |
| `store-members.csv` | Recovered semantic store fields/actions/getters. |
| `components.csv` | Vue components and member counts. |
| `component-members.csv` | Data/computed/method/watch/lifecycle members. |
| `classes.csv`, `class-members.csv` | Application JS classes and signatures. |
| `js-symbols-app.csv.gz` | Every non-vendor JS variable/function/method/class/accessor. |
| `routes.csv` | Vue client routes. |
| `private-api-sends.csv` | Client-to-server private WS send sites. |
| `private-api-responses.csv` | Server-to-client private WS handlers. |
| `public-rest-api.csv` | Reconstructed market-data REST path templates. |
| `network-summary.json` | Endpoints, timeouts and protocol summaries. |
| `firebase-callables.csv` | Callable Cloud Function names and references. |
| `storage-keys.csv` | IndexedDB/localStorage/Firebase keys and prefixes. |
| `build-environment-keys.csv` | Embedded environment key names only. |
| `order-strategy-constants.json` | Order/bot state and type constants. |
| `resource-inventory.csv` | Resource paths, sizes and hashes; no resource copies. |
| `web-assets.csv` | Embedded web asset paths, sizes and hashes. |
| `native-libraries.csv` | ELF metadata and classification. |
| `dependency-versions.csv` | Android dependency version markers. |
